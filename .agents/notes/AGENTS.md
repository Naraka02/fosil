# Agent Note instructions

Follow the [repository instructions](../../AGENTS.md). This subtree uses the [Agent Note rules](README.md), not the tutorial/reference document skeleton.

- Before adding a note, search for the decision's current owner and apply the [trigger rule](README.md#when-a-note-is-required).
- Use the prescribed [path and naming convention](README.md#paths-and-discovery), [class](README.md#classes), and [lifecycle-specific format](README.md#note-format).
- Check that metadata agrees with the file's directory and actual outcome. Apply the [transition and maintenance rules](README.md#transitions-and-continuing-ownership) when a decision changes state.
- Preserve real rationale and alternatives. Do not turn an implemented note into a proposal or rewrite a decision into its opposite; follow the [ownership rules](README.md#transitions-and-continuing-ownership).
- Keep archived notes frozen and treat them only as historical evidence under the [archive rules](README.md#transitions-and-continuing-ownership).

The [documentation standard](../../docs/AGENTS.md#language-and-writing) owns the shared language and writing rules. The [development guide](../../docs/development.md#documentation-checks) owns the review procedure.
