# Repository instructions

These instructions apply throughout the repository. A subtree's `AGENTS.md` adds instructions for that subtree; it does not duplicate or relax these rules.

- Read the [development guide](docs/development.md) and the instructions and active Agent Notes relevant to the task before editing. Follow its [working sequence](docs/development.md#working-sequence).
- Keep changes within the agreed scope and preserve existing work. Follow the [change boundaries](docs/development.md#change-boundaries).
- Keep each fact in its owning document and link to it elsewhere. Follow the [documentation standard](docs/AGENTS.md), including its language and writing rules, for repository documentation.
- Apply the [Agent Note trigger rule](.agents/notes/README.md#when-a-note-is-required) in the same change. Update an existing decision's note when appropriate instead of creating duplicates.
- Verify the changed behavior and report evidence and limitations according to the [verification and completion rules](docs/development.md#verification-and-completion).
- Do not commit, push, publish, or perform destructive Git operations without explicit authorization. Follow the [Git and delivery rules](docs/development.md#git-and-delivery).
- Follow the [safety rules](docs/development.md#safety) for credentials, external effects, and approval boundaries.
